# LocalBoard

Настольное приложение для рисования схем и досок на macOS — редактор Excalidraw в нативной оболочке, **полностью офлайн**. Доски лежат обычными файлами `.excalidraw` в вашей папке, сохраняются сами, никакого аккаунта, сервера и облака.

## Возможности

- Полный редактор Excalidraw: фигуры, стрелки с привязкой, текст, рисование от руки, изображения, библиотеки.
- **Список досок** в боковой панели — создание, поиск, переключение в один клик; панель можно закрепить. Правый клик по доске: переименовать или удалить (файл уезжает в Корзину).
- **Автосохранение**: правки уезжают в файл через секунду после того, как вы остановились. Запись идёт через временный файл, поэтому сбой посреди сохранения не может обрезать доску.
- Своя папка досок — любая на диске; выбранная запоминается между запусками. По умолчанию `~/Documents/LocalBoard`.
- Экспорт в картинку и файл — штатными средствами редактора.
- Русский интерфейс, тёмная и светлая темы.
- Сети нет вообще: в приложении запрещены исходящие соединения (`connect-src 'none'`), никакой телеметрии.

## Требования

macOS 12 (Monterey) или новее.

## Установка (готовое приложение)

Собирать ничего не нужно.

1. Скачайте последнюю версию со страницы [**Releases**](https://github.com/ilyaVasiliev1/localboard/releases/latest) — файл `LocalBoard.dmg`.
2. Откройте `.dmg` и перетащите **LocalBoard** в папку **Программы**.
3. **Первый запуск** — приложение не подписано платным сертификатом Apple, поэтому macOS один раз спросит подтверждение:
   - запустите LocalBoard (двойной клик). Появится предупреждение «неизвестный разработчик» — это нормально;
   - откройте **Системные настройки → Конфиденциальность и безопасность**, пролистайте вниз и нажмите **«Всё равно открыть»** напротив LocalBoard, подтвердите;
   - либо: правый клик по приложению → **«Открыть»** → **«Открыть»**.

   Это нужно **один раз**. Дальше приложение открывается как обычное.

## Работа с ИИ-ассистентом

В меню приложения есть пункт **«Работа с Claude…»** — три шага, с чего начать, и готовая команда запуска.

Самому ассистенту ничего объяснять не нужно: приложение кладёт в папку досок файл `CLAUDE.md` с полным протоколом, и агент, открытый в этой папке, читает его первым делом. Инструкция живёт рядом с досками намеренно — это делает решение переносимым: у любого, кто поставил приложение, ассистент разбирается сам, без настройки. CLI для чтения досок едет внутри бандла (`Contents/Resources/board.mjs`), поэтому репозиторий для этого не нужен.

Схемы приходят **чёрно-белыми**. Цвет на доске означает смысл, и расставляет его хозяин доски; схема, пришедшая уже раскрашенной, занимает этот канал первой. Палитра возвращается правкой ролей в [src/scheme-style.ts](src/scheme-style.ts).

## Схемы из терминала

Приложение следит за папкой `_inbox` внутри папки досок. Что туда положено — то ложится на **открытую** доску: раскладку считает mermaid, оформление берётся из `src/scheme-style.ts`, стрелки получаются привязанными, вставка попадает в историю правок и отменяется через Cmd+Z.

```bash
node scripts/board.mjs list                    # доски и число элементов
node scripts/board.mjs read "Пайплайн"         # пересказ доски: схемы, узлы, связи
node scripts/board.mjs send --mermaid схема.mmd --title "Диктовка" --anchor "Готовность"
```

`read` пересказывает доску словами, а не отдаёт сырой JSON: на двух сотнях элементов это разница между «понятно, что схема говорит» и десятками тысяч строк служебных полей.

Запрос можно положить и файлом — тогда доступны все поля:

```jsonc
{
  "title": "Пайплайн диктовки",
  "mermaid": "flowchart TD\n  a([Старт]) --> b[Шаг]",
  "place": "right",              // right | below | {"x": 0, "y": 0}
  "anchor": "Готовность",        // рядом с какой схемой — по тексту её узла
  "gap": 200,
  "roles": { "Старт": "terminal", "Отказ": "error" },
  "style": { "arrow": { "shape": "elbow" } }   // точечные правки канона
}
```

Стрелки бывают двух видов: `sharp` — прямая линия от блока к блоку (по умолчанию) и `elbow` — только прямые углы, для плотных схем, где связи идут в обход блоков. Дугообразных нет намеренно: на схеме из десятка блоков кривая читается петлёй, а не связью.

Роль узла по умолчанию выводится из формы: ромб — развилка, овал — терминал, остальное — шаг. `roles` переназначает её по тексту узла; доступны `step`, `decision`, `terminal`, `accent`, `error`.

Требования: приложение запущено и доска открыта. Без открытой доски запрос отклоняется — рядом с ним появится `.error.txt` с причиной, потому что вставлять схему было бы некуда.

## Как устроена работа с досками

Каждая доска — отдельный файл `.excalidraw` в выбранной папке. Это обычный JSON формата Excalidraw: его можно открыть на [excalidraw.com](https://excalidraw.com), положить в облако, отправить в мессенджер, держать под git.

Папка досок меняется по клику на её имя внизу боковой панели. Приложение помнит выбор и последнюю открытую доску.

## Сборка из исходников

Нужны **Node 20+**, **Rust** (stable), **Xcode Command Line Tools** и **yarn 1.x** (им собирается сам редактор).

```bash
git clone https://github.com/ilyaVasiliev1/localboard.git
cd localboard
./scripts/setup.sh          # принесёт Excalidraw на пиннутом коммите + npm install
npm run tauri dev           # запуск в режиме разработки
```

Редактор Excalidraw **не вендорится** в этот репозиторий: `scripts/setup.sh` клонирует его на строго зафиксированном коммите в `upstream-excalidraw/`, собирает его пакеты и подключает как `file:`-зависимости. Пин намеренный — LocalBoard собирается из пакетов редактора, поэтому «свежий master» однажды поменял бы API под ногами.

Наши правки самого редактора лежат в [patches/](patches/) и применяются `setup.sh` сразу после клона: апстрим в репозиторий не попадает, поэтому изменения в нём живут отдельными диффами, а не растворяются в чужом коде.

Первый `setup.sh` идёт долго: пакеты Excalidraw отдают `dist/`, которого в их репозитории нет, поэтому его приходится собирать (`yarn install && yarn build:packages`). Повторные запуски этот шаг пропускают.

### Обновление редактора

```bash
./scripts/update-editor.sh            # до последнего master Excalidraw
./scripts/update-editor.sh <коммит>   # до конкретного
```

Скрипт переставляет пин, заново накладывает патчи и пересобирает пакеты. Если патч не лёг на новый код — останавливается и говорит, какой именно: молча пропущенная правка означала бы, что удалённое вернулось, а никто не заметил.

Правило, по которому это остаётся дешёвым: всё, что можно сделать через публичный API редактора (props, children, `UIOptions`) или свои стили, делается так — такие изменения переживают обновление сами. Патч — последнее средство, и чем он меньше, тем реже конфликтует; патч из одних удалений не конфликтует почти никогда.

### Релизная сборка

```bash
./scripts/build-release.sh            # → .tmp/release-artifacts/LocalBoard.dmg
./scripts/build-release.sh --install   # то же + установка в /Applications
```

Скрипт собирает `.app`, подписывает ad-hoc и вручную оформляет DMG: фон, размер окна, позиции иконок. С сертификатом Developer ID (`SIGN_IDENTITY`, `NOTARY_PROFILE`) он же делает нотаризованный установщик.

`scripts/install-local.sh` ставит сборку в `/Applications` и удаляет прочие копии `LocalBoard.app` — на машине остаётся ровно одна, актуальная.
