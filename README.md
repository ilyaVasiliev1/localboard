# LocalBoard

Настольное приложение для рисования схем и досок на macOS — редактор Excalidraw в нативной оболочке, **полностью офлайн**. Доски лежат обычными файлами `.excalidraw` в вашей папке, сохраняются сами, никакого аккаунта, сервера и облака.

## Возможности

- Полный редактор Excalidraw: фигуры, стрелки с привязкой, текст, рисование от руки, изображения, библиотеки.
- **Список досок** в боковой панели — создание, поиск, переключение в один клик; панель можно закрепить.
- **Автосохранение**: правки уезжают в файл через секунду после того, как вы остановились. Запись идёт через временный файл, поэтому сбой посреди сохранения не может обрезать доску.
- Своя папка досок — любая на диске; выбранная запоминается между запусками. По умолчанию `~/Documents/LocalBoard`.
- Импорт готового `.excalidraw` — файл копируется в вашу папку, чтобы все доски лежали в одном месте.
- Экспорт в картинку и файл — штатными средствами редактора.
- Русский интерфейс, тёмная и светлая темы.
- Сети нет вообще: в приложении запрещены исходящие соединения (`connect-src 'none'`), никакой телеметрии.

## Требования

macOS 12 (Monterey) или новее.

## Установка (готовое приложение)

Собирать ничего не нужно.

1. Скачайте последнюю версию со страницы [**Releases**](https://github.com/ilyaVasiliev1/localboard/releases/latest) — файл `LocalBoard.dmg`.
2. Откройте `.dmg` и перетащите **LocalBoard** в папку **Программы**.
3. **Первый запуск** — приложение не подписано платным сертификатом Apple, поэтому macOS один раз спросит подтверждение:
   - запустите LocalBoard (двойной клик). Появится предупреждение «неизвестный разработчик» — это нормально;
   - откройте **Системные настройки → Конфиденциальность и безопасность**, пролистайте вниз и нажмите **«Всё равно открыть»** напротив LocalBoard, подтвердите;
   - либо: правый клик по приложению → **«Открыть»** → **«Открыть»**.

   Это нужно **один раз**. Дальше приложение открывается как обычное.

## Как устроена работа с досками

Каждая доска — отдельный файл `.excalidraw` в выбранной папке. Это обычный JSON формата Excalidraw: его можно открыть на [excalidraw.com](https://excalidraw.com), положить в облако, отправить в мессенджер, держать под git.

Папка досок меняется по клику на её имя внизу боковой панели. Приложение помнит выбор и последнюю открытую доску.

## Сборка из исходников

Нужны **Node 20+**, **Rust** (stable), **Xcode Command Line Tools** и **yarn 1.x** (им собирается сам редактор).

```bash
git clone https://github.com/ilyaVasiliev1/localboard.git
cd localboard
./scripts/setup.sh          # принесёт Excalidraw на пиннутом коммите + npm install
npm run tauri dev           # запуск в режиме разработки
```

Редактор Excalidraw **не вендорится** в этот репозиторий: `scripts/setup.sh` клонирует его на строго зафиксированном коммите в `upstream-excalidraw/`, собирает его пакеты и подключает как `file:`-зависимости. Пин намеренный — LocalBoard собирается из пакетов редактора, поэтому «свежий master» однажды поменял бы API под ногами.

Первый `setup.sh` идёт долго: пакеты Excalidraw отдают `dist/`, которого в их репозитории нет, поэтому его приходится собирать (`yarn install && yarn build:packages`). Повторные запуски этот шаг пропускают.

### Релизная сборка

```bash
./scripts/build-release.sh            # → .tmp/release-artifacts/LocalBoard.dmg
./scripts/build-release.sh --install   # то же + установка в /Applications
```

Скрипт собирает `.app`, подписывает ad-hoc и вручную оформляет DMG: фон, размер окна, позиции иконок. С сертификатом Developer ID (`SIGN_IDENTITY`, `NOTARY_PROFILE`) он же делает нотаризованный установщик.

`scripts/install-local.sh` ставит сборку в `/Applications` и удаляет прочие копии `LocalBoard.app` — на машине остаётся ровно одна, актуальная.

## Приватность

Всё локально. Доски — файлы на вашем диске, приложение не обращается в сеть ни при каких действиях, аккаунта нет.
