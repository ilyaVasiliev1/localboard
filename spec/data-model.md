# Модель данных

Хранилище продукта — файловая система. Базы данных у продукта нет, поэтому
ограничения держит код и сама файловая система; у каждого ограничения ниже
названо, кто его держит.

---

## DM-board — Доска на диске
Доска хранится одним файлом в подключённой папке.

Поля файла:

```
имя         — строка: имя файла без каталога, расширение .excalidraw
содержимое  — JSON формата Excalidraw: elements, appState, files
папка       — строка: каталог, в котором лежит файл
```

- Уникальность имени внутри папки держит файловая система: создание,
  переименование и перенос на занятое имя система ОБЯЗАНА отклонять с причиной.
- Имя доски нигде, кроме имени файла, не хранится — расходиться ему не с чем.
- Новая доска создаётся с пустой сценой: `elements` — пустой массив.
- links: TERM-board
- impl: app:src-tauri/src/main.rs

## DM-config — Настройки приложения
Приложение хранит подключённые папки в файле `config.json` в каталоге
поддержки приложения.

```
folders     — массив строк: пути к папкам досок
boards_dir  — строка или пусто: прежняя единственная папка; читается только
              ради переноса на список и после первого сохранения исчезает
```

- Пустой список означает папку по умолчанию `~/Documents/LocalBoard`; система
  ОБЯЗАНА создать её при первом запуске.
- links: TERM-folder
- impl: app:src-tauri/src/main.rs

## DM-request — Запрос схемы
Запрос схемы — файл `.json` в ящике схем.

```
mermaid      — строка, обязательное: текст схемы на mermaid
title        — строка, необязательное: подпись над схемой
place        — below | right | {x, y}; по умолчанию below
anchor       — строка, необязательное: текст узла схемы, рядом с которой ставится новая
gap          — число, по умолчанию 200: отступ от опорной схемы в точках
roles        — соответствие «текст узла → роль», необязательное
style        — точечные правки канона оформления, необязательное
```

- Закрытый перечень: поля сверх названных система не читает.
- links: TERM-scheme-request, TERM-scheme-role
- impl: app:src/scheme-inbox.ts
