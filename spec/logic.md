# Правила

Как система себя ведёт.

---

## L-001 — Автосохранение доски
Когда человек перестал править доску, система сохраняет её через задержку
автосохранения. Ручного сохранения в продукте нет.
- links: INV-001, API-boards.save, EC-005
- impl: app:src/App.tsx

## L-002 — Опрос ящика схем
Пока приложение открыто, система осматривает ящики подключённых папок через
период опроса и кладёт найденный запрос на открытую доску.
- links: INV-002, API-inbox.take, API-inbox.finish, EC-013, EC-014, DEP-mermaid
- impl: app:src/App.tsx, app:src/scheme-inbox.ts

## L-003 — Граница между папками
Схема ложится только на доску той папки, в ящик которой положен запрос. Если
доска этой папки не открыта, система запрос не исполняет.
- links: EC-014, TERM-folder
- impl: app:src/App.tsx

## L-004 — Удаление доски в корзину
Когда человек подтверждает удаление, система переносит файл доски в корзину
пользователя. Занятое имя получает числовой суффикс.
- links: EC-007, API-boards.delete
- impl: app:src-tauri/src/main.rs

## L-005 — Подготовка подключённой папки
Когда папка подключена или прочитана, система создаёт в ней ящик схем и
кладёт инструкцию ассистента рядом с досками.
- links: TERM-guide, TERM-inbox, EC-005
- impl: app:src-tauri/src/main.rs

## L-006 — Сверка с диском
Пока окно открыто, система сверяет список досок с диском через период сверки, а
также в момент возвращения фокуса в окно.
- links: INV-004, API-boards.list, EC-005
- impl: app:src/App.tsx

## L-007 — Обновление только по нажатию
Система проверяет обновление, когда человек выбрал пункт меню, и никогда сама.
Загрузка и установка идут после согласия человека, доски при этом не
затрагиваются.
- links: API-update.check, INV-003, INV-005, EC-010, EC-011, EC-012
- impl: app:src/updates.ts

## L-008 — Последняя доска запоминается
Когда приложение открывается, система показывает доску, с которой человек
работал в прошлый раз, а при её отсутствии — пустое состояние списка.
- links: UI-sidebar.boards, EC-005
- impl: app:src/App.tsx

## L-009 — Схемы приходят чёрно-белыми
Система кладёт схему из ящика без заливки и без цвета обводки сверх канона
оформления. Роль узла выводится из формы, заданной mermaid, и переназначается
полем запроса.
- links: TOK-scheme.stroke, TOK-scheme.fill, TOK-scheme.stroke-width, TOK-scheme.roughness, TOK-scheme.roundness, TOK-scheme.arrow-color, TOK-scheme.arrow-width, TOK-scheme.title-size, TERM-scheme-role
- impl: app:src/scheme-style.ts

## L-010 — Одна копия приложения
Когда приложение запускается второй раз, система выводит вперёд уже открытое
окно вместо второй копии.
- links: TERM-board
- impl: app:src-tauri/src/main.rs

## L-011 — Схема попадает в историю правок
Когда схема положена на доску, система добавляет её как обычную правку сцены,
поэтому отмена возвращает доску к состоянию до вставки.
- links: API-inbox.take, EC-009
- impl: app:src/scheme-ops.ts

## L-012 — Раскладка схемы
Система размещает схему ниже последней либо правее неё, а при указанной опорной
схеме — рядом с нею; отступ берётся из запроса. Форма связей выбирается по виду
схемы: линейная цепочка получает прямые линии, схема с ветвлениями — прямые
углы с обходом.
- links: DM-request, TOK-scheme.arrow-shape, DEP-elkjs
- impl: app:src/scheme-layout.ts
