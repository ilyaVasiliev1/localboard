# Инварианты

Величины, которые нельзя нарушать. Значение живёт здесь, а не в коде.

---

## INV-001 — Задержка автосохранения
От последней правки доски до записи файла — 1200 мс.

- measure: задержка между последним изменением сцены и вызовом сохранения, мс
- threshold: 1200 мс
- method: константа задержки в коде интерфейса и проверка тестом на таймерах
- links: L-001, API-boards.save
- impl: app:src/App.tsx

## INV-002 — Период опроса ящика схем
От появления запроса в ящике до его разбора — не более 1500 мс.

- measure: период опроса ящика, мс
- threshold: 1500 мс
- method: константа периода в коде интерфейса; проверка — запрос кладётся в
  ящик при открытой доске, замеряется появление схемы
- links: L-002
- impl: app:src/App.tsx

## INV-003 — Ожидание ответа о версии
Проверка обновления ждёт ответа не дольше 45 секунд.

- measure: предел ожидания ответа хранилища релизов, с
- threshold: 45 с
- method: константа предела в коде проверки обновлений; проверка — вызов при
  недоступной сети
- links: L-007, API-update.check, EC-010
- impl: app:src/updates.ts

## INV-004 — Период сверки с диском
Список досок расходится с диском не дольше 4000 мс, пока окно открыто.

- measure: период сверки списка досок с диском, мс
- threshold: 4000 мс
- method: константа периода в коде интерфейса; проверка — файл доски
  создаётся в Finder, замеряется появление строки в списке
- links: L-006
- impl: app:src/App.tsx

## INV-005 — Тишина интерфейса
Число исходящих соединений, доступных веб-части приложения, — ноль.

- measure: число разрешённых интерфейсу исходящих соединений
- threshold: 0
- method: политика безопасности окна объявляет `connect-src 'none'`; проверка —
  чтение конфигурации приложения и попытка запроса из интерфейса
- links: L-007
- impl: app:src-tauri/tauri.conf.json

## INV-006 — Нижняя граница системы
Приложение запускается на macOS 12.0 и новее.

- measure: минимальная версия macOS в собранном бандле
- threshold: 12.0
- method: поле минимальной версии в конфигурации сборки и `defaults read` по
  собранному бандлу
- links: DEP-tauri
- impl: app:src-tauri/tauri.conf.json
