# Краевые случаи

Одно условие на атом.

---

## EC-001 — Название доски занято
В папке уже есть доска с таким именем — система отклоняет создание,
переименование остаётся без изменений, файл на диске не трогается.

## EC-002 — Название не даёт имени файла
Введённое название не содержит имени файла — система отклоняет создание и
переименование с причиной «Некорректное название».

## EC-003 — Папки назначения нет
Каталог, в который переносится доска, отсутствует — система отклоняет перенос,
доска остаётся на месте.

## EC-004 — Имя занято в папке назначения
В папке назначения уже есть доска с таким именем — система отклоняет перенос,
доска остаётся на месте.

## EC-005 — Папка исчезла с диска
Подключённая папка переименована, удалена или унесена на отключённый том —
система убирает её из списка и сохраняет сокращённый список; файлы в ней не
трогаются.

## EC-006 — Подключается несуществующий каталог
Указанного каталога нет — система отклоняет подключение с причиной «Такой папки
нет», список папок не меняется.

## EC-007 — Корзина недоступна
Каталога корзины нет — система удаляет файл доски напрямую. Корзина на другом
томе — система копирует файл и удаляет исходный.

## EC-008 — Ящик схем пуст
Запросов в ящике нет — система отвечает пустым результатом и не создаёт файлов.

## EC-009 — Запрос схемы не разобрался
Текст mermaid не превращается в схему — система кладёт рядом с запросом файл
`.error.txt` с причиной и удаляет файл запроса.

## EC-010 — Обновление: ответа нет 45 секунд
Ответ от хранилища релизов не пришёл за 45 секунд — система сообщает об этом
человеку и оставляет установленную версию.

## EC-011 — Обновление: соединения нет
Сеть недоступна — система сообщает, что проверить обновление не получилось, и
оставляет установленную версию.

## EC-012 — Обновление прервалось при загрузке
Связь прервалась во время загрузки — система сообщает, что обновление не
установлено, и оставляет установленную версию рабочей.

## EC-013 — Открытой доски нет
Запрос схемы пришёл, когда ни одна доска не открыта — система отклоняет запрос
и кладёт причину рядом с ним: вставлять схему некуда.

## EC-014 — Запрос адресован чужой папке
Запрос лежит в ящике папки, доска из которой сейчас не открыта, — система
оставляет его в ящике и на открытую доску не кладёт.
