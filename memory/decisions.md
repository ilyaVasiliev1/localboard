## 12.08.2026 — стек `macos-tauri`

Заведён под этот продукт: ни один существующий модуль не покрывал связку
«веб-интерфейс в нативной оболочке». Статус `proven` выдан решением Ильи до
полного живого доказательства — иначе круг не разрывается: `lint` и `test` на
продукте невозможны, пока в нём нет конфигураций и тестов, а эта работа
делается прогоном, который без `proven`-стека не начинается.

Что продукту предстоит, чтобы соответствовать стеку: конфигурации eslint и
prettier, первые тесты, перенос логики оболочки из `main.rs` в библиотечную цель
(у бинарной цели юнит-тесты невозможны), чинка замечания clippy `sort_by_key`,
восемь файлов по стилю.

## 12.08.2026 — доставка двумя ступенями

Staging — локальная пересборка и установка на машину Ильи, production — релиз
на GitHub с артефактами автообновления. Предварительной среды у продукта нет и
не заводится: исполняется он на машине человека.

Открыто: подпись. Локальная сборка ad-hoc, релизная может быть с Developer ID —
тогда руками проверяется не то, что уедет людям. Решается при заведении адаптера
доставки.

## 12.08.2026 — переезд сломал путь к ключу подписи

`scripts/build-release.sh` ищет ключ обновлений относительно каталога проекта
(`../../secrets/`). После переезда путь указывает в несуществующий каталог, а
ключ остался на прежнем месте. Сборка от этого не падает — она молча соберёт
DMG без артефактов автообновления.

Не починено: место тайн проекта — решение Ильи.
