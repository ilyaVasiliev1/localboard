# Исходники оформления

Иконки, из которых собран бандл приложения. В сборку **не попадают** — лежат здесь как источник, а не как ресурс времени выполнения (когда они лежали в `public/`, Vite копировал 4.5 МБ вариантов иконки в каждый DMG).

- `icon/localboard-icon-flow.png` — текущая иконка приложения (светлая карточка со схемой); из неё собран `src-tauri/icons/`.
- `icon/localboard-icon.png`, `icon/localboard-icon-modern.png` — отвергнутые направления (фиолетовая плашка с кривой).
- `*-source.png` — исходные рендеры в полном разрешении.

Пересобрать набор размеров под macOS/Windows после замены иконки:

```bash
npm run tauri -- icon design/icon/localboard-icon-flow.png
```
